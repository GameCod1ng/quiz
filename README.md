# 바이브 코딩 퀴즈 앱

`questions.json`에서 문제 10개를 불러와 푸는 객관식 퀴즈 앱입니다. 점수, 오답 노트, 다시 풀기를 지원합니다.

## 실행 방법

`fetch`로 로컬 파일을 읽기 때문에 간단한 서버가 필요합니다.

```
cd D:\quiz
npx serve
```

터미널에 나온 주소(예: http://localhost:3000)를 브라우저로 엽니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| index.html | 화면 뼈대 (시작 / 문제 / 결과) |
| style.css | 모양과 색 |
| app.js | 동작 (불러오기, 채점, 오답 노트, 다시 풀기) |
| questions.json | 문제 데이터 |

## 문제 추가하기

`questions.json`에 항목을 추가합니다. `answer`는 0부터 시작하는 보기 번호입니다.
